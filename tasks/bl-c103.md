Every commit balls authors on this box is born on an artificial day: the real time-of-day is mapped by one affine function into a configured window (real date preserved). Replaces the hand-installed ~/.cargo/bin/bl shim.

Design (living doc): ~/dev/bl-workhours/docs/design.md (repo committed 7814ecd).

CONVERGED SHAPE (design session 2026-07-07; reshaped from the PATH-wrapper baseline):
- NOT a hook plugin: §6 plugins have no return channel and run as core's children, so a plugin can't set core's clock or env; the delivery squash (close.pre, before the store seal) compounds it.
- NOT a PATH wrapper: it works (a wrapper is core's parent, env inherited) but is invisible to bl conf / off the schedule. Kept in the doc as the recorded subtractive baseline.
- IS a clock-provider: with the SSOT fix, the op's instant T is a first-class input with a resolution ladder; the provider is the top rung. In-system (config, bl install, [source] hints), no return channel (core PULLS one scalar at op-start).

The window IS the persona (no direction knob): [09:00,17:00) = never-works-late; [18:00,23:30) = the shim's moonlighter effect. One affine map, every op, every day -- all three shim conditionals (is-close / work-hours / weekday) dissolve.

Two children: (1) the core SSOT fix + clock_provider knob; (2) the provider binary. Done when both close.
