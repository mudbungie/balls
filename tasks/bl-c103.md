Replace the hand-installed ~/.cargo/bin/bl shim with a versioned, tested PATH wrapper that maps every commit balls authors on this box onto an artificial day (real time-of-day -> a configured window by one affine map; real date preserved).

Design (living doc): ~/dev/bl-workhours/docs/design.md (repo git-initialized, design committed bb79e01).

Key decisions from the design session (2026-07-07):
- NOT a balls plugin. §6 plugins have no return channel and run before core seals, so they cannot bend the store clock or the delivery clock. A PATH wrapper runs in the parent process and exports env core's git subprocesses inherit -- the only position from which the clock moves.
- The window IS the persona (no direction knob): [09:00,17:00) reads as 'never works late'; [18:00,23:30) reproduces the shim's moonlighter effect. Same affine map, two numbers.
- One branchless map replaces all three shim conditionals (is-close / work-hours / weekday).
- Two seams: GIT_*_DATE (all git commit dates; works today) + BALLS_CLOCK (core seam so published frontmatter created/updated agree with git dates). Both children below.

Box-local, fail-open. Done when both children close.
