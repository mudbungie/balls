docs/architecture.md §3, in the `blockers` bullet, ends with:

> Pure-metadata links (`relates_to`, `supersedes`, `duplicates`, `replies_to`)
> remain core metadata with no enforcement.

Nothing implements this. `Task` (src/task.rs) carries `title, created, updated,
claimant, parent, priority, root_commit, blockers, tags, extra, body` — no link
fields. No flag writes them, no query reads them, no skill doc names them. An
agent reading §3 would believe the schema has four fields it does not have.

Raised by a balls-vs-beads comparison (github.com/gastownhall/beads), which
frames the one `{id, on}` edge plus containment as deliberate subtraction that
costs knowledge-graph queries. The evaluation says it costs nothing — but that
verdict is only defensible if the spec actually STATES the rejection, and today
it states the opposite.

The fix is subtraction plus a reason, not a schema. Replace the sentence with a
rejection naming where each fact already lives:

- `duplicates`/`supersedes` — both relations become true exactly when the other
  ball CLOSES, and close deletes the file (§9). §10/bl-6b8c already refuses an
  edge to a dead target ("an edge born resolved — a blocker that can never
  block, and a primitive must mean what it says"), so the edge would be born
  meaningless. The fact belongs in `bl close -m`, retrievable where it is asked:
  `show` resolves a dead id out of history and folds the journal.
- `replies_to` — threaded comments. balls has no comment object; the body is
  edited in place and the store branch's history IS the thread, rendered
  oldest-first by `show`'s journal. Storing it would store what git computes.
- `relates_to` — relatedness is an equivalence CLASS, not a pairwise edge, and
  `tags` names the class: `list --tag` returns the whole cluster in one query,
  where a pairwise graph needs N^2 edges and a traversal for the same answer.

Residue stated, not hidden: a genuinely pairwise live-to-live annotation is
prose-only and not machine-reachable. No verb would consume it; a team that
wants it anyway has the `extra` seam, which round-trips an unknown key
untouched — severable, zero core.

Deliverable: docs/architecture.md §3 edited. No schema change, no flag, no verb.
