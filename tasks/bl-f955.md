The CI/CD rewrite in bl-7954 replaced release-plz.toml wholesale, dropping the
`{ message = "^balls:", skip = true }` commit parser the old file carried. That
was a regression: `git log main` has `balls:`-prefixed commits (e.g.
`86e0e917 balls: trim reverted bl-2656 churn from the v0.5.5 changelog`,
`03a3db6e balls: trigger release-plz after workflow re-enable (0.5.0)`) which
are release/changelog housekeeping by this repo's own tooling — they maintain
the changelog, so they must not appear in it.

Restore the skip parser ahead of the catch-all, with a comment saying why.
