Two-part core change in the balls repo. Part A is cleanup worth doing regardless; Part B is the workhours-specific hook that rides it.

PART A -- SSOT (the latent bug). An op reads the wall clock THREE times that agree only by luck: mutate::now() (frontmatter created/updated ints), core's seal() 'git commit -F -' (NO --date, so git's own clock stamps the store commit), and the delivery plugin's commit-tree (main squash, a third process). Fix:
- Core captures ONE instant T at op-start.
- Stamps frontmatter with T (as today, but now overridable).
- Sets its OWN seal commit's GIT_AUTHOR_DATE/GIT_COMMITTER_DATE = T (git.rs seal() currently sets no date).
- Exports GIT_*_DATE = T into EVERY plugin's spawn env (plugin.rs), so the delivery squash inherits it. Propagation is parent->child (allowed; core already sets BALLS_PROTOCOL etc.), never child->parent.

PART B -- the resolution ladder for T:
    clock_provider (config -> a bound binary)  >  BALLS_CLOCK (test-only env)  >  SystemTime (default)
- clock_provider names a binary resolved via the SAME config/plugins/bin/<name> symlink as hooks (§6) and bound by bl install --bin, so it shows in bl conf + carries a [source] hint -- but wired by a SCALAR key, not [hooks] (it resolves an INPUT, not an effect).
- Provider protocol: core runs <bin>, reads one line (unix-seconds i64) from stdout, exit 0.
- FAIL-OPEN and NON-FATAL: missing bin / non-zero exit / unparseable -> log + fall down the ladder. The one deliberate asymmetry with hook dispatch (a dangling hook bin ABORTS): a hook is load-bearing, the clock is cosmetic with a sane default, so it degrades not blocks.

BYTE-IDENTICAL when nothing is set (no provider, no BALLS_CLOCK -> SystemTime, today's behavior).

DOC: the §15 flag (open topics / reserved seams), cross-ref from § id generation: the *.pre worktree-reassign seam is the general override for FILE-materialized inputs (id via git mv, frontmatter); the clock is the SOLE op-start input outside that family (not file-representable), so it gets this one core-resolved hook -- one knob, not a framework (bl-587f 'no consumer yet' bar). bl-chore docs child applies.

TESTS: T override -> frontmatter AND store commit date AND delivery squash date all == T; provider missing/erroring -> SystemTime (fail-open); BALLS_CLOCK test seam. 100% coverage.
