The accepted cost from docs/design/bl-7b71-nested-delivery.md, made visible. Needs the mechanism ball.

Under nesting a closed child is DELIVERED to its target but not LANDED on main, and absence is a closed balls whole record. At epic scale (hours) that is benign; at release scale (weeks) a ball can be closed and invisible for a month.

The answer is NOT a stored field — whether work is on main is `git merge-base --is-ancestor` against its delivery tag, and the query surface is schema-axes-complete. It is a RENDERED column: `bl list` shows a balls target when that target is not the integration branch, exactly as the root-aware `--everywhere` labels are render-only decoration over a derived fact (bl-0161). Projection grows, schema does not.

Open in scope: whether the same decoration belongs on `bl show`, and whether a landed-vs-delivered marker on the CLOSED side is worth the git query per row (it likely is not for list; it likely is for show, which already reads one ball deeply).
